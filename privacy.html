Privacy Policy

This page explains the information the site currently collects and why.

Reader accounts

The site uses Supabase anonymous authentication so readers can use comments, polls and engagement features without creating an email account. An anonymous reader account has a unique technical user ID. Your chosen display name may be stored with your comments and reader profile.

Engagement data

The site may store poll votes, comment likes, article likes, saved articles and article reading activity against an anonymous reader account. This is used to provide the site's features and aggregate publication statistics.

Newsletter

If you subscribe to the newsletter, your email address is stored so it can be used for the newsletter list. The current site stores the subscription but does not yet have an automated email delivery provider connected.

Hosting and technical data

The site is hosted through GitHub Pages. GitHub states that visitors to GitHub Pages sites can have IP addresses logged and stored for security purposes. See GitHub's own privacy documentation for details.

Third-party services

The site currently uses GitHub Pages, Supabase, Pages CMS and a public X feed service. Each provider may process technical data under its own terms and privacy policies.

Your choices

If you want a comment, reader profile or newsletter subscription removed, contact the publication via @AskBritain_ on X. We will handle requests where we have the practical ability and legal basis to do so.
